# О базе знаний

По умолчанию здесь лежат README четырёх открытых проектов автора — они выбраны
как самодостаточный, уже публичный набор документов на тему AI-агентной
инфраструктуры, чтобы демо было честным «из коробки»: не нужен доступ к
чужим/закрытым данным, чтобы его запустить.

- `jarvis-telegram-gateway.md` — мост Telegram ↔ Claude Code (github.com/qwwiwi/jarvis-telegram-gateway)
- `public-architecture-claude-code.md` — переиспользуемая архитектура памяти и safety-хуков для Claude Code агентов
- `edgelab-claude-md.md` — методология CLAUDE.md / многоуровневой памяти агентов
- `architecture-brain-tests.md` — тестовый набор для агентной инфраструктуры

## Как заменить на свои документы

Удалите эти файлы (или оставьте — `ingest.py` индексирует всё содержимое
папки без разбора) и положите сюда свои `.md`/`.html` файлы, затем:

```bash
python3 ingest.py
```
